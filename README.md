# 莓好时光

Android 原生离线消消乐原型，使用 Kotlin 和 Jetpack Compose 构建。

## 在 Android Studio 中运行

1. 在 Android Studio 中打开此项目根目录。
2. 等待 Gradle 同步完成，并安装 Android SDK 35（如果尚未安装）。
3. 连接 Android 手机或启动模拟器，运行 `app` 配置。

项目最低支持 Android 8.0（API 26）。

## 当前玩法

- 交换相邻格子，匹配三个或以上同色水果消除；棋盘初始为 8×8。
- 每关初始 3 回合，每回合 10 秒；三回合内累计达到 1200 分即可通关。
- 回合结束时若尚未通关，会在棋盘中加入最多 4 个杂色水果；杂色总数不超过棋盘格子的 20%。
- 每消除一个角色颜色的水果，对应角色获得 1 点能量；能量满 12 点后可主动释放技能。
- 角色技能分别是：随机转换 20% 水果、清除中间三列、当前回合加 5 秒、清除最多 20% 杂色水果。
- 可以暂停/继续游戏，暂停时回合计时停止；技能发动后会短暂高亮其影响区域或计时器。
- 角色技能充能完成后，技能按钮会脉动高亮并显示可释放提示。
- 失败可以重开；通关可进入下一关。

关卡成长参数集中在 `GameConfig`：回合数、每回合时间、棋盘尺寸、目标分数均会随关卡调整。角色颜色为用户提供的 RGB 值。

美术暂用 Compose 绘制的纸片、胶带和水果色块占位，后续可以替换为正式素材。
